## Retinal Wave Pre-training in Connectome-Constrained Visual Networks

Before mammals can see, their retinas produce spontaneous activity patterns called retinal waves. These waves play an important role in the early development of the visual system. Previous research has shown that retinal waves can be useful for pre-training artificial neural networks. This thesis aims to investigate whether similar benefits can be achieved in connectome-constrained networks, where the connections between neurons are based on real biological structures.

The main research question is whether pre-training with retinal waves can help a connectome-constrained network develop useful visual processing abilities. For this purpose, the thesis will use FlyVis, a model based on the visual system of fruit flies. Since retinal waves naturally occur in mammals, it is unclear whether similar results can be achieved with the fly visual system.

The experiments will start with an untrained FlyVis model and a dataset of simulated retinal waves. One approach is to use self-supervised optical flow learning to train the network to estimate motion between frames. Another approach is to send retinal wave activity directly to internal neurons instead of using the normal visual input. After training, the network will be tested with visual stimuli and compared with the untrained model. The evaluation will focus on which neurons become active, how they respond to different stimuli, and whether they show useful visual processing abilities.

Depending on the results, other training methods and retinal wave simulations may be explored. One possible direction is to train a model to generate retinal waves and study what kind of activity patterns it learns. These generated patterns could then be used for further pre-training experiments. If time permits, the experiments may also be extended to a mammalian visual system using available connectome data, such as the MICrONS mouse visual cortex dataset (MICrONS Consortium et al., 2025).
